PYTHON INPUT 
from datetime import datetime
from decimal import Decimal
import datason

data = {
    "created": datetime(2026, 10, 4),
    "price": Decimal("19.99"),
}
text = datason.dumps(data,
                     include_type_hints=False)
print(text)

GOOD QUESTIONS.

Before you
cross the boundary.

Clear contracts make better software. Here’s what to expect.

How is this different from Python’s json?

The interface is familiar, with additional type handlers and explicit policies. Defaults differ: datason emits Unicode directly, converts non-finite numbers to null, and includes type tags. Read the compatibility guide.

Will every Python object round-trip?

Restoration depends on the type and settings. Application models normalize to fields; some ML handlers export metadata only. Redaction and non-finite policies can change values. Check the supported-type contracts.

Do I have to install all the ML libraries?

No. The core has zero runtime dependencies. Install only the extras you use, such as NumPy or Pandas. Custom types can have their own plugins. See the installation choices.

What about untrusted data and stored models?

Typed reconstruction is intended for trusted application-owned snapshots and reviewed plugins. Input budgets do not sandbox library code. For ordinary incoming JSON, disable plugin reconstruction. Understand the trust boundary.

Which version should I use?

These examples work with the published v2 alpha (2.0.0a1), available through pip. The detailed docs track newer development source (2.0.0a2), including changes since that release. An unqualified pip install datason selects stable v1 (0.13.0), which has a different API. Check current release and installation guidance.
